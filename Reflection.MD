TaskMaster Backend Reflection

This project helped me put together several backend skills in one application. I practiced building Express routes, connecting MongoDB Atlas with Mongoose, creating models, and using CRUD operations.

One challenge for me was understanding the difference between authentication and authorization. I learned that authentication checks whether a user is logged in, while authorization checks whether that user has permission to access a specific project or task.

I also practiced password security with bcrypt and learned how JWT tokens can protect private routes. The task routes were the most challenging because I had to find the task, find its parent project, and then check whether the logged-in user owned that project.

This project gave me a better understanding of how a real backend API can organize users, projects, tasks, security, and database relationships.
