TaskMaster Backend Reflection

This project helped me bring together the backend skills I learned in class. I practiced using Node.js, Express, MongoDB Atlas, Mongoose, bcrypt, JSON Web Tokens, routes, models, middleware, and CRUD operations in one application.

One of the biggest challenges for me was understanding the difference between authentication and authorization. I learned that authentication checks whether a user is logged in, while authorization checks whether the logged in user has permission to access a specific project or task.

I also learned how bcrypt protects passwords by hashing them before they are stored in MongoDB. I used JSON Web Tokens to protect private routes and identify the logged in user.

The task routes were more challenging because I had to find the task, find its parent project, and then check whether the logged in user owned that project.

This project gave me a better understanding of how a backend API can connect users, projects, tasks, security, and a database.
